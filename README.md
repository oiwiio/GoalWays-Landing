# Goal Ways — лендинг

Адаптивный лендинг мобильного приложения **Goal Ways** — умного помощника в достижении целей. Пользователь ставит цель с помощью ИИ или вручную, делит её на задачи и двигается к результату без прокрастинации. Сейчас доступен MVP для Android.

Лендинг презентует приложение и ведёт на скачивание APK (Яндекс Диск и GitHub).

> Само приложение разрабатывается отдельно (React Native + TypeScript, Zustand, React Navigation, Axios + TanStack Query). Этот репозиторий содержит только лендинг: это статичный сайт на чистых HTML/CSS/JS без фреймворков и сборщика.

## Возможности

- Адаптивная вёрстка: 320px, 768px, 1024px, 1440px+
- Семантический HTML5, доступные вкладки шагов (ARIA, управление стрелками)
- Блок «Три шага до первой цели»: вкладки меняют текст и скриншот приложения
- Сдержанные анимации: вход hero, лёгкое «парение» телефона, hover на карточках, пульсация свечения в CTA
- Анимации отключаются при `prefers-reduced-motion`
- Без зависимостей, кроме шрифта Montserrat (Google Fonts)

Для проверки на телефоне или в локальной сети удобнее поднять сервер:


После этого откройте `https://oiwiio.github.io/GoalWays-Landing/`.

## Скриншоты приложения

Блок шагов показывает скриншот под каждый шаг. Файлы кладутся в `assets/`:

| Шаг | Файл по умолчанию |
|-----|-------------------|
| 01 — Поставь цель | `assets/создание цели.jpg` |
| 02 — Разбей на задачи | `assets/step-2.jpg` |
| 03 — Настрой под себя | `assets/step-3.jpg` |
| 04 — Двигайся к результату | `assets/step-4.jpg` |

Требования к скринам: пропорции около 9:19 (например, 1080×2280), одинаковый размер у всех, без рамки телефона (рамку рисует CSS). Если файл не найден, вместо него показывается CSS-заглушка. Другие имена и форматы указываются в атрибутах `src` в `index.html`.

Скриншот в hero пока заглушка: чтобы заменить, вставьте `<img class="phone__img" src="…" alt="…">` внутрь `.phone` в секции `.hero`.
